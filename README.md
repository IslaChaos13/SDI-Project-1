# SDI-Project-1

:star: **Overview** :star:
This application is an interactive survey platform designed for fans of televisiona nd film culture. Users can explore a selection of tv shows, actors, and actresses while participating in a survey that collect audience opinions, preferences and trends.
------
Features
:film: Entertainment Showcase :film:
The application provides users with a selection of tv shows, actors and actresses that can be browsed and explored through an organzied and visually appealing interface.

:paper: User Survey System :paper:
A built in survey system allows users to submit their preferences regarding gengres of TV Shows.
